# Peixes

Suba aqui os sprites e skins dos peixes.

Cada peixe deve ter uma pasta própria quando possuir mais de um arquivo.

Exemplo:
`assets/fish/peixe-dourado/`
- `idle.png`
- `hooked.png`
- `icon.png`
- `sprite-sheet.png`

Para sprite sheets, mantenha todos os frames com a mesma célula e fundo transparente.

O código do jogo deve apontar para esses arquivos através do registro central de assets, não por caminhos espalhados pelo projeto.
