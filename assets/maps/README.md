# Mapas e cenários

Suba aqui os mapas e partes de cenário do jogo.

Sugestão de organização:
- `main/` mapa principal.
- `backgrounds/` fundos completos.
- `tiles/` peças reutilizáveis.
- `props/` píer, barcos, pedras, plantas e objetos.

Formatos preferidos: PNG/WebP. Para elementos com recorte, use fundo transparente.

Exemplos de nomes:
- `mapa-principal-v1.png`
- `ceu-dia.png`
- `agua-base.png`
- `pier-madeira.png`
